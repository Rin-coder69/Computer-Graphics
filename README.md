# Computer Graphics

A collection of **Computer Graphics projects and demos** implemented in **C++** (with **OpenGL/GLSL**) for learning and experimenting with foundational graphics programming concepts. This repository contains example code, rendering demos, and core graphics techniques useful for students, hobbyists, and anyone interested in real-time rendering or graphics APIs.

## 🖥️ Overview

This repository explores classic computer graphics topics using C++ and OpenGL, including:

- Rendering 2D and 3D shapes
- Shader programming (GLSL)
- Real-time interactive graphics
- Graphics pipeline fundamentals
